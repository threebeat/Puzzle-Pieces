# Puzzle Pieces — author atlas

Made for Tiffany. Complete spoilers; current playable collection.

## Overall progression

Start in the Long Hall. Collect the plan and IV brochure from reception in the center of the hall. I, II and III can be solved in any order. Their three seals, the washroom card and the hanging-weight order converge in Security. Set ○ → ⌜ → ⋈ and submit to open the upper north terrace. Hold its south-facing, level view for 2.5 seconds. This marks the first visit; exploration continues.

The single south-wall public stair reaches only the west mezzanine. There are no bridges. East-side access requires Security acceptance and the employee stair. IV is public from the south-wall stair and supplies evidence for B1. Card → Security training and accepted print → South Service → inspection lift → manifest audit → clearance → freight to Upper. The same Security print releases the conference room, closet and garage: dispatch FRAME → workshop square CARE / AREA / REAR / EARN → secret Counterform return. Accepted inventory numbers restore only the local lower circuit. IV, the audit and circuit are not prerequisites for the terrace milestone.

The card opens Security only. The accepted sheet lights the service cable and releases the employee wing. The northern secret also waits for certification. Public lifts start isolated; restore their supply upstairs after using the employee stair. The conference-table key opens the glass gift shop. Staff stairs reach the loft, break room and optional third-floor rooms. South inspection always returns from B1.
